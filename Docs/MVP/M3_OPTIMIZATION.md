# M3：两项深入优化实验

规划状态：待开始。实际状态由 `Docs/PM/` 维护。

前置：列表轨依赖 [M1](M1_LIST_LAB.md)有效基线；渐变轨依赖 [M2](M2_GRADIENT_LAB.md)有效基线。

后继：两轨与汇总完成后进入 [M4](M4_SHOWCASE.md)。

## 1. 主题与目标

每条组件主线回答一个清晰的工程问题：窗口内更新一个 item 时，如何避免无关 Bind；非线性渐变在给定质量目标下，如何选择足够而不过量的 segment。M3 展示性能分析方法和取舍，不以“必须更快”作为验收。

## 2. 阶段成果

- M3-L：刷新窗口基线、可见 index→cell 映射、真正单项绑定及正确性／性能对照。
- M3-G：固定 8／16／32／64 段质量—成本曲线、自适应算法、上限和回退对照。
- 两项实验各一份冻结协议、原始数据、诊断证据、决策记录和学习页。
- 最终默认策略：可选择新方案、条件启用或维持基线，并说明边界。

两条轨道可以独立分析；共享源码导入、Unity Editor 和性能机器时写入／运行串行。每项实验先冻结问题与指标，避免看到结果后改变成功条件。

## 4. M3-L1：定位窗口刷新成本

M1 基线的 `RefreshCell(index)` 保持刷新可视窗口。针对相同数据和视觉，只触发一项内容变化，分别计数：数据写入、目标是否可见、Bind 调用、属性实际变化、vertex／layout dirty、Canvas rebuild 和帧时。

Case 至少覆盖：可见中部、可见边界、刚离屏、完全离屏、滚动中、模板变化、数据插入／删除导致 index 移位。诊断区分“重新调用 Bind”与“Graphic 实际重建”；不能用 Bind 降低直接宣称 Canvas 同比例降低。

M3-L1 的输出是假设和可复现瓶颈，不修改实现来获得收益。如果成本主要来自数据后续链路而不是窗口 Bind，M3-L2 仍可实现正确映射，但性能预期需相应缩小。

## 5. M3-L2：真正单项刷新

维护可见 `data index → active cell` 映射，并与 Rent／Bind／Unbind／Return 原子更新。合同包括：

- 仅可见目标存在时 Bind 一次；离屏更新只更新数据，不创建 Cell。
- 滚动窗口、数据 reset、插入／删除、模板变化、尺寸变化和 rebuild 会使哪些映射失效。
- 复用前移除旧 index，再绑定新 index，任何时刻映射与租赁所有权一致。
- Cell 回调触发嵌套刷新时采用队列、版本或明确拒绝，避免遍历中破坏集合。
- 诊断不保存已销毁对象，不因映射本身造成长期引用。

A/B 保持 M1 实现、数据、场景和动作不变，只改变刷新策略。代表频率包括稀疏更新、突发少量更新和高频更新；当大量可见项同时变化时，允许窗口批量路径更合理，并记录切换条件。

**通过条件：**所有映射和生命周期 Case 通过；可见单项 Bind count 符合合同，离屏不创建；CPU／Canvas／GC 差异按实际数据分别报告。若最终总成本无清晰差异，也可完成实验并维持简单基线。

## 6. M3-G1：固定段数曲线

使用 M2 同一颜色函数和合法矩形，扫描 8／16／32／64 segment。至少覆盖代表尺寸、水平／垂直、中心与极端 bias、静态和持续变化。

质量指标在实验前定义，例如在密集参考采样点上比较真实曲线与分段线性插值的 RGBA 最大／均方误差，并以固定截图误差补充。必须写明插值颜色空间和 alpha 权重；数值误差不是感知质量的万能替代。

成本包含 segment 选择以外的顶点／索引生成、缓冲、Mesh 更新、Canvas rebuild、上传和渲染。报告实际顶点／三角形，不从 segment 数口头推算。

M3-G1 输出质量—成本 Pareto 观察和预先选择的代表误差目标，为自适应算法提供基准；不先指定 32 一定过量。

## 7. M3-G2：自适应细分

推荐从整段开始，对区间中点（必要时增加四分点）的真实曲线与端点线性插值误差进行估计；超过阈值则递归／迭代拆分，直到满足误差或达到 `maxSegments`。具体算法在 Brief 冻结，并满足：

- `minSegments`、`maxSegments` 和确定性输出；极端参数不会无限循环或爆炸增长。
- 达到上限仍超误差时明确 `quality_limited`，不能伪称达标。
- 相邻截面共享顶点，位置严格单调；退化输入使用 M2 fallback。
- 参数未变化时可复用选择结果；缓存 key、失效、内存和计算成本纳入测量。
- 与固定 32 的比较使用相同曲线、误差评估、场景和动作。

静态配置分别报告一次构建成本和持续渲染成本；动态过渡报告每次选择和重建成本。段数下降不保证 CPU 或帧时改善，自适应选择本身可能更贵。

**通过条件：**算法在上限内满足目标或准确标记超限；输出确定、拓扑和 M2 回归通过；质量与成本数据有效。性能更差时保留实现作为实验分支／模式，默认可以继续固定 32。

## 8. M3-05：决策与学习验收

每项决策记录包含：

1. 原观察和冻结假设。
2. 只改变了什么，哪些条件保持一致。
3. 正确性和测量有效性。
4. 每轮数据、效果量和相对基线波动。
5. 收益、退化、无清晰差异或 inconclusive 的结论。
6. 复杂度、内存、维护和适用边界。
7. 最终默认、可选开关或回退决定。

用户学习复盘与技术完成分开记录，但 M4 最终验收前两项核心实验都需要有可复述的解释。至少能独立解读一段相关 Profiler trace，并说明它不能证明什么。

## 9. 阶段出口

- M3-L2 和 M3-G2 的 required 正确性回归通过，数据绑定到冻结候选和协议。
- 两项实验均有有效对照或诚实的 invalid／inconclusive 原因及恢复计划；没有选择性删除运行。
- M3-05 选择了最终默认策略，M1／M2 代表回归已复跑。
- 负结果和失败方案保留在实验记录中，作品集文案不只展示漂亮数字。
- 变高缓存、手工定位和 Shader 对照仍属于扩展，未替代两个必需实验。
