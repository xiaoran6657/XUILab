# 个人主页项目交接

主页是独立的github.io项目。本仓库只交付案例与素材，不包含网站框架、部署代码或页面运行依赖。当前资料版本v0.1.0-preview.1，发布访问状态由[公开交付记录](PUBLICATION.md)维护。

## 取用顺序

先用[PROFILE](PROFILE.md)的一句话定位和简介制作项目卡片，再按三个CASE制作案例页。推荐阅读顺序为项目概览、演示、问题与实现、结果和限制、源码与下载。

[资料清单](PUBLISHING_INPUTS.json)逐项给出图片/视频尺寸、用途、SHA-256；source字段只用于本地生成，不是网站URL。仓库内[Media](Media/)包含12张1600×900图片，[Data](Data/)包含两份报告及历史被测输入清单。[公开原始数据包](PUBLIC_DATA.md)提供130次运行的复算入口。大型媒体由版本Release分发；网站可以取用已经发布并核验哈希的文件，不依赖本机Artifacts。

## 视频呈现

三视频均1280×720、45秒、15fps、无音轨。为帧驱动技术演示，捕获真实耗时与播放时长可能不同，禁止标成实时性能录像。主页使用封面、播放控件与邻近文字说明；不要自动播放三个视频。内容说明沿用[MEDIA](MEDIA.md)，可为各操作时间点添加字幕，但应声明新增字幕属于网页说明或后期版本。

## 内容边界

性能结论必须带场景和测量指标。保留inconclusive、Fixed32 quality_limited、硬件环境与缺失指标，不用最好一轮替代全部结果。个人贡献应描述实际参与，不根据文档存在声称用户已独立掌握全部实现。完整PM、原始机器日志与私人参考材料不作为首页素材。

## 稳定依赖

网站使用明确tag的源码/Release地址和相对素材路径，不绑定main分支的可变哈希，不使用本地绝对路径，也不热链接尚未发布的附件。升级资料版本时核对manifest与展示文案；SHA只证明完整性，不能替代结果解释。新机器或浏览器加载、视频拖动、移动端布局和无障碍由主页项目验收。
