# 最终候选性能结果

当前130次有效独立Player运行已完整复算：列表50次、渐变80次。源码候选相同，两主题各用其首场景Development构建；主题内A/B二进制相同，不能跨主题比较绝对帧时。身份、原始数据、失败尝试和构建见[证据索引](EvidenceIndex.md)。

## 统计口径

每次预热300帧、采样1800帧，每组五对独立进程，交错执行；先算每次p50/p95/p99，再汇总五次的中位数和范围。下表变化为两策略的p95五轮中位数之差，不是五个点再取p95。判据预先固定：五对至少四对同方向，且差值超过 max(基线中位数的5%, 两策略p95全距较大者的一半)。这是本项目操作性阈值，不是显著性检验或总体因果证明。

### 质量与算法成本

Fixed32在极端bias连续RGBA误差约0.0384221，超过0.01目标，标记quality_limited；Adaptive实际使用1–12段，动态最大误差0.009941919907、极端静态约0.00723906，均在目标内。64只是上限，不是每次使用的段数。两策略不具有相同质量，因此本实验是既有Fixed32基线与满足当前质量目标的Adaptive比较，不能宣传为等质量方案的严格最优性能排名。

单组件最大顶点66→26，100组件最大6600→2600；中心bias自适应为1段/4顶点。颜色量化误差另计，动态最大约0.00195986；它不是连续近似误差或屏幕像素误差。质量结论仅覆盖协议规定的矩形Image、uniform white base、RGBA/Schlick参数和动态600个bias，不保证任意纹理、Shader、非均匀底色或任意曲线。

动态网格自适应选择器在1800采样帧内累计耗时中位158.5597ms，已经包含在总帧间隔中；不可再从p95中直接减去这个累计值。静态稳定窗口不重复选择，冷选择与冷构造单列；它们也不能当作GPU完成时间。保留Fixed32默认、Adaptive显式可选的现有实现，当前M4不据数字更改产品默认。

## 环境、不可用指标与失败

Unity2022.3.45f1c1，Windows10 10.0.19045 64bit，Ryzen5 5600G（12逻辑处理器）、Radeon RX9070，D3D11，960×540，High Fidelity、Linear、Mono Development，VSync0。列表另有60FPS对照，其余targetFrameRate=-1。所有最终有效运行在本轮Editor关闭状态完成；没有混入旧跨日M3数据。

Frame Interval是墙钟帧间隔，不是主线程CPU时间。两主题Main Thread、GC Allocated In Frame、System Used Memory均unavailable，UI/GPU独立耗时未采集；保留null，不能声称零GC/零内存增长。控制文件和原始environment记录决定完整环境身份。

列表原第15次180秒timeout无raw；原渐变r1首个尝试因ListLab首场景接收错误入口参数exit2无raw。两次失败的日志/启动/终态均保留并分别修复启动前台获取、主题构建入口；失败没有被改成success，也没有伪造逐帧样本。Release里的normal/fail/invalid演示是独立诊断，不进入上述正式矩阵。
